

Android app for navigating Cebu jeepney routes with full backend API integration.

## Features
- Register / Login with Bearer Token authentication
- Dashboard with PUJ route search
- Profile view and update
- Change password
- Photo upload

## Tech Stack
- Android (Kotlin)
- Retrofit2 for API calls
- Supabase (Backend + Auth + Storage)
- SharedPreferences for session management

## API Integration
- Base URL: `https://flypldzauiktytljifaf.supabase.co/`
- Auth: Bearer Token
- Format: JSON

## Error Handling
- ✅ No internet connection
- ✅ Invalid credentials (400)
- ✅ Unauthorized (401)
- ✅ Server error (500)
